# ⚙️ 1C:УТ 11 — REST API Расширение для мобильного ТСД

Расширение конфигурации для **1С:Управление торговлей 11 (1С:УТ)**, реализующее REST API (HTTP-сервисы) для обмена данными с мобильным терминалом сбора данных.

> 📱 **Клиентская часть проекта (React Native App + Mock Server):** [github.com/Liptor/project_1c_mobile](https://github.com/Liptor/project_1c_mobile)


---

## 🎯 Назначение и архитектура

Расширение разработано без снятия типовой конфигурации с поддержки (режим совместимости с **1С:Предприятие 8.3**). Вся бизнес-логика вынесена из модуля HTTP-сервиса в общий серверный модуль в соответствии со стандартами разработки 1С.

### Состав объектов расширения:
* **HTTP-сервис `ut_api` (корневой URL: `/v1`):**
  * `GET /ut_api/hs/v1/catalog` — выгрузка актуальной номенклатуры (исключая группы и помеченные на удаление элементы).
  * `POST /ut_api/hs/v1/orders` — прием заказа от мобильного клиента, проверка на дубли по `localId` и создание документа `ЗаказКлиента`.
* **Общий модуль (Сервер):**
  * Обработка входящих JSON-запросов, формирование ответов, транзакционная запись документов и логирование ошибок в `ЖурналРегистрации`.

---

## 🔌 Описание методов API

### 1. Получение каталога номенклатуры
* **Метод и URL:** `GET /ut_api/hs/v1/catalog`
* **Ответ (`200 OK`):**
```json
[
  {
    "id": "a1b2c3d4-e5f6-47a8-9b0c-1d2e3f4a5b6c",
    "name": "Кабель ВВГнг 3х2.5",
    "article": "KGN39VL316"
  }
]
```

### 2. Создание заказа (с защитой от дублей)
* **Метод и URL:** `POST /ut_api/hs/v1/orders`
* **Тело запроса:**
```json
{
  "localId": "1731675000000-a1b2c",
  "item": {
    "name": "Кабель ВВГнг 3х2.5",
    "article": "KGN39VL316"
  }
}
```
* **Логика обработки:** Перед созданием документа выполняется проверка наличия заказа с переданным `localId` (защита от повторной отправки при нестабильном мобильном интернете на складе).
